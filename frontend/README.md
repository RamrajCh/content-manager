# Frontend

Next.js App Router, strict TypeScript and Tailwind CSS. The Phase 1 page is a
development placeholder, not a working catalog or checkout.

Use the root [local development instructions](../README.md) for prerequisites,
startup, validation and the separate backend/service processes.

From this directory: `npm ci`, `npm run dev`, `npm run lint`, `npm run build`,
and `npm run typecheck`. Development and production-preview commands bind to
127.0.0.1. `/api/*` forwards only to the fixed local backend at port 5080;
deployment routing is deferred.
